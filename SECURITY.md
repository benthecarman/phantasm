# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Phantasm, please report it
privately by emailing [benthecarman@live.com](mailto:benthecarman@live.com).
Please do not open a public issue for an unpatched vulnerability.

Include as much of the following as you can:

- The affected component and version or commit
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation or fix

You should receive an acknowledgement within seven days. Please allow a
reasonable amount of time for the issue to be investigated and fixed before
public disclosure.

## Supported versions

Phantasm is currently under active development. Security fixes are applied to
the latest code on the default branch; older revisions are not supported.
